# The Query Battery — standard measurement protocol

The battery is 10 queries per client, fixed at baseline and never reworded afterward — a moved goalpost kills the measurement. Build it once per client from the template below, save it in the client's record, and run the identical set every month.

## The 10-slot template

Replace bracketed terms with the client's actual service, city, and named competitors.

1. **The money query:** "best [service] in [city]"
2. **The hiring query:** "who should I hire for [job-to-be-done] in [city]"
3. **The recommendation query:** "recommend a [service provider] near [city]"
4. **The comparison query:** "[client name] vs [top competitor]"
5. **The vetting query:** "is [client name] legit / worth it / any good"
6. **The reviews query:** "[client name] reviews"
7. **The how-to-choose query:** "how do I choose a [service] company"
8. **The problem query:** "[the pain the client solves, as a buyer would phrase it]" — pull phrasing from the avatar bible, not from the client's site.
9. **The price query:** "how much does [service] cost in [city/region]"
10. **The category-adjacent query:** one query from the buyer's upstream problem (e.g., for Churlish: "how do I get more customers for my [trade] business" — does video/authority marketing even enter the answer?)

## Engines and recording

Run each query against: ChatGPT, Claude, Perplexity, Gemini, and Google AI Overviews. Same wording, fresh session, no logged-in personalization where avoidable.

Record per query per engine, in a running sheet:

| Field | What to capture |
|---|---|
| Mentioned | yes / no |
| Position | first named / in the list / footnote |
| Framing | recommended / neutral / cautioned |
| Source leaned on | the citation or the evident origin (directory, GBP, Reddit, own site, press) |
| Verbatim answer | paste it — the ledger needs receipts |

Share of answer = queries with at least one mention across engines, out of 10. Also track first-position count separately — being the ninth name in a list is not the same asset as being the answer.

## Rules

- Baseline before any fix ships. No baseline, no program.
- Never reword a query mid-program. Add new queries only as slots 11+ with their own start date.
- Log the run date; engines shift, and the date is part of the receipt.
- Where the engine cites a source, that source goes to the top of the fix-stack review — fix what the machine actually reads, not what an SEO checklist says it should read.
