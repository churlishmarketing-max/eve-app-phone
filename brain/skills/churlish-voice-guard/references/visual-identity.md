# Churlish Media Visual Identity

## Document formatting standards

These rules apply to all formatted outputs — .docx proposals, PDFs, presentations, HTML landing pages, and any other visual deliverable.

## Typography

### Primary system (HTML, presentations, branded assets)
- **Headlines:** Barlow Condensed, 900 weight. Big, bold, compressed. Used for hero text, section headers, and anything that needs to command a page.
- **Body:** Barlow, 400 weight (regular) and 700 weight (bold for emphasis).
- **Display sizes:** 36–72px depending on hierarchy level and impact needed.
- **Body sizes:** 13–18px.

### Document system (DOCX, internal docs, SOPs)
- **Headlines:** Arial Black (or Arial Bold as fallback)
- **Body:** Arial, regular weight
- **These fonts are used because** they render consistently across all systems and don't require font installation from the client.

### Color usage rules

1. **Red is punctuation.** Use it sparingly — one red element per composition. It's the period at the end of a bold statement, not the sentence itself. A single red accent on a page draws the eye. Three red elements fight each other.

2. **Teal is the workhorse accent.** Section headers, callout box borders, icon fills, divider lines. Teal does the structural work that keeps the design from being monochrome without competing with red.

3. **Gold marks premium.** Divider lines between major sections, accent on tier names ("Authority System"), callout box borders on high-value information. Use less frequently than teal.

4. **Cream backgrounds for documents.** Unless the deliverable is specifically dark-themed (social graphics, video thumbnails), use the warm cream (#F0EDE8) as the page background with #F8F5F0 for inset sections. This separates Churlish docs from the generic white-page default.

5. **Dark theme for digital-first assets.** Social posts, thumbnails, presentation slides, and landing pages use the deep black (#0A0A0A) background with white text and accent colors.

## Document structure patterns

### Proposals
- Cover page: client name, project title, Churlish Media branding, date
- Situation analysis / diagnosis section (what we see)
- Recommendation section (what we'd build)
- Scope and deliverables (specific, listed)
- Pricing table — tiered, side-by-side comparison when multiple options exist
- Timeline
- Closing section with next step CTA
- Back page with Churlish contact info

### Strategy documents
- Cover page
- Executive summary (1 paragraph — the "why this matters" distillation)
- Situation analysis with data
- Strategy framework with named sections
- Monthly/quarterly deliverables breakdown
- Revenue model or KPI targets (always include numbers)
- Responsibility matrix (who does what)
- Timeline with milestones

### SOPs
- Header with SOP number, title, and "Prepared by Churlish Media"
- Purpose statement (1–2 sentences)
- Step-by-step process with numbered sections
- Templates and scripts embedded inline (not as separate appendices)
- Objection handling or troubleshooting tables where relevant
- Quick-reference checklist at the end

## Image treatment (color grade reference)

When describing visual treatment for video or photo assets:
- Shadows: Push teal/blue (#1E3A4C)
- Midtones: Desaturate slightly
- Highlights: Warm or neutral
- Contrast: High, crush the blacks
- Vignette: Subtle, cinematic
- Red accent: In graphics ONLY — never in the color grade itself
