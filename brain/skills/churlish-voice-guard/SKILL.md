# Churlish Voice Guard

This skill defines how Churlish Media sounds, looks, and presents across every deliverable. Read `references/voice-rules.md` before writing any Churlish copy. Read `references/visual-identity.md` before creating any formatted documents (docx, PDF, presentations, HTML).

## When to use

Every time you produce written output for Churlish Media or a Churlish client. This includes but is not limited to:
- Client proposals and pitch decks
- Ad scripts (Meta, YouTube, CTV)
- Email sequences and nurture flows
- Social media captions and carousel copy
- Strategy documents and gameplans
- Blog posts and long-form content
- Video scripts (long-form and short-form)
- Landing page and website copy
- Client-facing SOPs and playbooks

## How to use

1. Read `references/voice-rules.md` to internalize the writing voice
2. If the output is a formatted document, also read `references/visual-identity.md`
3. Apply the voice rules while writing — they override generic "professional" or "corporate" defaults
4. When in doubt, ask: "Would Brandon say this on camera?" If it sounds like a LinkedIn post from a marketing agency, rewrite it

## The litmus test

Every piece of Churlish copy should pass three checks:
1. **Is it direct?** No throat-clearing, no corporate hedging, no "leveraging synergies." Say the thing.
2. **Does it earn attention?** The first sentence should make someone stop scrolling or keep reading. If the opening is deletable, delete it.
3. **Does it move someone?** Every piece has a job — build trust, create urgency, handle an objection, or ask for the next step. If it doesn't do one of those, it's decoration.
