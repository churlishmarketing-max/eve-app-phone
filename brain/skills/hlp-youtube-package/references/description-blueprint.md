# HLP Description Blueprint

The HLP description is a fixed structure. Keep the section order and the emoji headers exactly — they're the channel's signature and they make the description scannable. Write everything in Churlish voice (read `churlish-voice-guard`).

## The locked structure

```
[COLD-OPEN HOOK — 2–3 sentences. The single most arresting fact or contradiction
from the episode, written as a story, no preamble. This is the above-the-fold text,
so the first ~12 words have to stop the scroll. Lead with the guest's sharpest beat.]

[WELCOME PARAGRAPH — "On this episode of High-Level Pros, Brandon sits down with
[guest + one-line identity]…" Then 3–4 sentences laying out the arc of the
conversation: the origin, the turn, the failure, the payoff. Name the concrete
stuff (numbers, places, the deal) so it reads like substance, not hype.]

[ONE-LINE BRIDGE — what makes this episode worth the runtime. Often the giveaway or
the counter-intuitive promise.]

THE LESSON
[The single strongest takeaway, framed for an operator. This is usually the
counter-intuitive truth or the tactical spine. 2 short paragraphs max. State the
principle, then the proof from the episode. No fluff — these readers bounce on it.]

THE HOMEWORK
[Every HLP episode has homework — surface it. If the guest gave a concrete,
copy-pasteable process (a framework, a checklist, a step list), lay it out cleanly
here; this is the most screenshot-able part of the description. If there are two
homeworks (guest's + Brandon's), lead with the tactical one and close with Brandon's.]

⏱️ CHAPTERS
00:00 — [hook-style chapter]
[MM:SS or H:MM:SS] — [hook-style chapter]

```

## Writing each section

**Cold-open hook.** Pick the fact that creates the biggest "wait, what?" — a shocking number, a contradiction, a reversal. Write it like the opening line of a story. Example energy: a hard number that shouldn't go with the person's job, or a result that shouldn't be possible. Never open with "In this episode…"

**Welcome paragraph.** Always starts "On this episode of High-Level Pros, Brandon sits down with…". Establish the guest's identity in one line, then walk the arc in plain language. Pack in the concrete details (a $40K deal, a city, a specific tool) — concreteness is what separates this from generic podcast copy.

**THE LESSON.** Choose the takeaway that serves the operator audience, not the most emotional moment. State the principle in one line, then back it with what happened in the episode. Two short paragraphs is the ceiling.

**THE HOMEWORK.** This is a signature of the show and a retention/engagement driver. If the guest handed over a real process, format it as numbered steps so it's screenshot-able. Note the value framing if there is one ("used to cost $X, now free with…"). End with a one-line "garbage in, garbage out" type caveat if relevant.

## Chapters

- First chapter is always `00:00`.
- Use `MM:SS` under an hour, `H:MM:SS` over.
- Write each as a curiosity hook, not a topic label: "The $40K deal that ghosted" beats "Business story."
- Pull real beats from the transcript and keep them close to what was actually said.
- A 60–80 min episode supports ~20–26 chapters; that depth helps watch-time and SEO.
- Auto-transcripts drift a second or two — if the source looks garbled, tell the user to confirm in-points by ear.

## Tags

15–25 tags. Primary keyword (the unique angle, e.g. "cop turned marketer") first. Mix: the angle + variations, guest name, Brandon King, Churlish Media, the topic cluster (AI/business/faith/etc.), and "Omaha business podcast." No single-word tags.

## Honest flags inside the description

- Frame the guest's bigger claims as their story, not channel-stated fact.
- Leave obvious `[fill in: …]` markers for any handle/URL not certain from the transcript — never invent one.
- Keep any verbatim quote under 15 words; paraphrase by default.
