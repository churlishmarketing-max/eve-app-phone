# EVE Desktop

EVE Desktop is her brain given a room instead of a pocket — one brain on Railway, a second surface on the desk, and a shell that holds zero intelligence and exactly one secret.

## Setup

1. Install Node 20+.
2. `npm install`
3. `npm run dev`

The deck opens. If no bearer token is set yet, open **THE WIRE** (settings) — the brain URL comes prefilled to the Railway app, and you paste the token once. It goes straight into the Windows Credential Vault (`safeStorage`) and is never displayed again after that.

`EVE_BRAIN_URL` and `EVE_BRAIN_TOKEN` env vars override both values for testing. They're read live and never persisted to disk.

## The surfaces

- **Command Deck** — the three-column home: the presence rail, TALK, and the live day-ops stack (TODAY / OPS / BODY).
- **Summon overlay** — `Ctrl+Space` from anywhere. Tap to talk, tap again to send.
- **Tray** — state-colored, quiet-hours aware. Click it for a flyout with approvals in it.

## What she will not do — by design

- **RED confirms mean nothing sends without you.** Anything that leaves the building — send, publish, spend — only ever queues a confirm card. She never simulates or claims it happened.
- **No canned lines.** Every sentence you see from her is generated by the brain, live. Empty states and labels are chrome, not her voice.
- **Honesty states, never fake zeros.** Offline says so in plain language, and the floor never shows a false zero. The title-bar dot flips LINK to DOWN when the brain can't be reached.
- **Quiet hours, 21:30-06:30, are her law, not a setting.** Nothing pings in that window; the tray dims.
- **Push-to-talk only. She never listens uninvited.** No open mic in v1 — a wake word is a v2 law change with its own consent screen, not something this build adds quietly.

## Verify the build

```
npm run smoke   # offline, mock brain, 9 checks
npm run shots   # writes verify/deck.png + verify/summon.png
```

What the machine proves: IPC wiring, that the renderer can't see a token or a raw `ipcRenderer`, the quiet-hours boundary math, and mock state reaching the UI through the real path.

What only your hardware proves: mic capture and the hold gesture on the mic button, the global hotkey in a real OS session, the tray icon in your live notification area, ElevenLabs actually audible through your speakers, and the first real conversation — that one's yours.

## Costs

None added here. Model calls happen brain-side on Railway; this shell doesn't pick models or spend on its own. Push-to-talk-only input is the attention gate — nothing listens until you tell it to.
